# Z8N - Constructor de Flujos

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Licencia](https://img.shields.io/badge/licencia-MIT-green)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)

**Constructor visual de flujos de trabajo** con sistema de nodos, conexiones y pizarra de ideas. Diseñado para crear y visualizar flujos de procesos de manera intuitiva.

---

## 🚀 Características

- 🎨 **Editor visual de nodos** con arrastrar y soltar
- 🔗 **Conexiones entre nodos** con animaciones personalizables
- 📝 **Notas adhesivas** para ideas y comentarios
- 🎯 **Categorización automática** de nodos por tipo
- 🎨 **Tema oscuro/claro** integrado
- 💾 **Persistencia local** (localStorage) - sin servidores
- 📦 **Exportación/Importación** de proyectos en JSON
- 🖼️ **Exportación a imagen** (PNG, SVG)
- 🎬 **Exportación a video** (WebM)
- 🔍 **Búsqueda de nodos** en tiempo real
- 🎯 **Nodos personalizados** configurables

---

## 🛠️ Tecnologías utilizadas

### Frontend
- HTML5, CSS3, JavaScript (ES6+)
- SVG para conexiones y gráficos
- Canvas 2D para renderizado

### Persistencia
- localStorage API
- Exportación/Importación JSON
